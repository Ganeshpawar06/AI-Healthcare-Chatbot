# 🩺 AI-Powered Medical Chatbot for Disease Prediction

An intelligent healthcare chatbot that predicts possible diseases based on user-reported symptoms using Machine Learning. The system utilizes a Random Forest Classifier trained on symptom-disease datasets to provide disease predictions, confidence scores, descriptions, and precautionary recommendations.

## 🚀 Features

* 🤖 Interactive conversational chatbot interface
* 🩺 Disease prediction from symptoms using Machine Learning
* 🔍 Symptom extraction from natural language input
* 📝 Fuzzy matching for typo correction and symptom recognition
* 🔄 Symptom synonym mapping for improved understanding
* 📊 Confidence score for predictions
* 📖 Disease descriptions and medical information
* 🛡️ Personalized precaution recommendations
* ❓ Dynamic follow-up questions for more accurate diagnosis
* 💙 User-friendly healthcare experience with empathetic responses

## 🛠️ Technologies Used

* Python
* Scikit-learn
* Pandas
* NumPy
* Random Forest Classifier
* Natural Language Processing (NLP)
* Fuzzy String Matching

## 📈 Workflow

1. User describes symptoms in natural language.
2. The chatbot extracts and normalizes symptoms.
3. A trained Random Forest model predicts the most likely disease.
4. Additional disease-specific questions are asked to improve accuracy.
5. The final prediction is displayed with:

   * Disease name
   * Prediction confidence
   * Disease description
   * Recommended precautions
